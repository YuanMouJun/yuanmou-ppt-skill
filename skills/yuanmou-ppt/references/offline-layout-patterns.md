# 渊眸离线高定排版语法卡（Offline Layout Patterns）

> 当处于**纯离线环境（无外部索引库）**，或选版引擎返回 `fallbackRecommended: true`（如科研消融表、极简暗黑硬件发布会、老板一页纸）时，按本语法卡配合 `@yuanmou/pptx-kit` 原生原语弹性构建。
> **核心原则**：本卡提供的是**网格比例、留白纪律、字号阶梯与结构语法**，而非千篇一律的死坐标圆角卡片；每页须按真实内容条目数动态计算行列宽（优先 `fr/fixed` 表格、`svgPath` 矢量与锐利细线分割）。

---

## 全局美术馆视觉底线（1280×720 画布）

- **页边距安全区**：左右 `64px`，顶栏标题区 `top: 40..124px`，正文主版心 `top: 144..648px`（净高 `504px`、净宽 `1152px`），底栏注脚 `top: 676px`（`10–11pt` 浅灰）。
- **字号阶梯**：页面主标题（结论前置 Action Title）`24–28pt Bold`；眉标/分类签 `11–12pt Bold`（全大写或字距微拉）；卡片/模块小标题 `15–17pt Bold`；正文与表格单元格 `>=12pt`（严禁 `<12pt` 挤字）；核心 KPI 大数字 `36–56pt Bold`。
- **配色克制铁律**：整套仅用 **1 个主色 + 1 个点缀强调色 + 2 阶中性灰**；背景与容器靠 **细分割线（`1px`）+ 极浅底色差（如 `#FFFFFF` vs `#F8FAFC`）** 建层次，严禁满屏粗描边彩色圆角卡片。

---

## <a id="pattern-keynote-hero"></a>1. 发布会暗黑巨幕 / 产品剖面标注（`hero_statement`）

- **适用场景**：品牌新品发布会、核心命题宣言、单一超大数字突破、硬件产品剖面拆解（Cutaway Callout）。
- **画风语法**：
  - 底板：深邃纯暗底（`#090D16` 或 `135°` 微梯度 `#0B1120 -> #152238`），文字主白 `#F8FAFC` + 辅灰 `#94A3B8` + 单一金属/科技强调色（如香槟金 `#D4AF37` 或电光青 `#38BDF8`）。
  - **巨幕金句版**：左对齐或绝对居中，全页仅保留 **1 句 10–18 字宣言（`44–64pt Bold`）+ 1 行极短副注（`16pt`）+ 1 条 `48×3px` 强调短横线**，留白 `>=60%`。
  - **产品剖面标注版**：居中放透明/暗底融入的产品主视觉（宽 `420–520px`），左右各排 `2–3` 组标注（小标题 `15pt Bold` + 1 句参数 `12.5pt`），用 `connector` 细折线 + `6px` 实心圆点精准指向产品部位。

---

## <a id="pattern-message-house"></a>2. 跨行业信息屋 / 战略屋（`message_house` / `pyramid_layers`）

- **适用场景**：品牌 Message House、企业战略屋、政策总体框架、科研「总命题 + 创新支柱 + 实验底座」。
- **三段垂直比例（版心高 `504px`）**：
  1. **顶部屋顶区（高 `108px`）**：用顶部浅梯形或深主色通栏横条（宽 `1152px`），居中承载唯一核心主张（`20–22pt Bold`）与一句话定义。
  2. **中部 N 根支柱区（高 `276px`，`gap: 20px`）**：根据内容数量动态均分 `3` 或 `4` 列（`colW = (1152 - (N-1)*20) / N`）；每根支柱用 **顶部 `4px` 主色强调横条 + 极浅灰底 `#F8FAFC`（无粗边框）**，内置「支柱编号 + 观点小标题 + `2–3` 条精炼支撑论据（`makeBulletList`）」。
  3. **底部横向基座（高 `88px`，与支柱间距 `16px`）**：通栏深灰/浅主色基座条，左侧标签（如 `RTB 信任状` / `底层保障`），右侧水平排 `3–4` 项硬核背书或数据指标（用 `1px` 细竖线分隔）。

## <a id="pattern-layered-architecture"></a>3. 多层技术架构 / 生态治理图（`layered_architecture` / `ecosystem_flow`）

- **适用场景**：B2B 售前技术架构、数据中台、科研端-边-云平台架构、组织治理体系。
- **结构语法（主栈 + 两侧纵贯护栏）**：
  - 若有安全/运维/标准等纵贯保障，左右各留 `116px` 竖向护栏条（文字竖排或居中简短分行），中间净宽 `888px` 排 `3–4` 层横向堆栈；无护栏时中间占满 `1152px`。
  - 每层横向堆栈结构：左侧 `140px` 深色层名标签（如「应用层 / 引擎层 / 算力底座」）+ 右侧浅底容器内动态均分 `3–5` 个功能模块（**小模块直接单 `<p:sp>` 合一设 fill+text，绝不框中套框**）。
  - 层间用极克制双向细箭头或 `12px` 清晰留白表达调用关系；严禁五颜六色彩虹堆砌（同色系深浅阶梯最佳）。

---

## <a id="pattern-swimlane-gantt"></a>4. 营销波段甘特 / 里程碑路线图（`swimlane_gantt` / `milestone_roadmap`）

- **适用场景**：整合营销传播节奏、项目筹备甘特图、Q1–Q4 年度规划、品牌发展历程。
- **泳道甘特语法**：
  - 顶部阶段头：`左栏 160px（泳道维度）` + 右侧按 `3–4` 个阶段均分（如 `预热期 / 爆发期 / 延续期`），深主色表头底 + 浅灰纵向阶段分隔细虚线贯穿全高。
  - 中部 `3–5` 条横向泳道：交替 `#FFFFFF` 与 `#F8FAFC` 底纹，每条泳道内按起止阶段精确落位实心/半透明胶囊波段条（`height: 36–44px`，条内直写核心动作，不另盖文本框）。
  - 底部可选一条 `48px` 阶段核心目标/KPI 里程碑汇总带。
- **里程碑时间轴语法**：一条 `2px` 水平主轴线 + `4–5` 个交替上下分布的节点（实心圆锚点 + 垂直细引线 + 年份/阶段大号强调字 + 2 行精炼事件）。

---

## <a id="pattern-event-rundown"></a>5. 活动精确时刻表 / 执行分工矩阵（`event_rundown`）

- **适用场景**：线下大会/年会精确 Rundown、发布会执行脚本、物料与人员分工表（`copyPolicy: "preserve"` 主力）。
- **表格语法**：
  - 直接调用原生 `s.tables.add({ columnTracks: [fixed(128), fixed(180), fr(2.2), fr(1.3), fixed(136)], ... })`，确保每一格均可在办公软件中直接增删改。
  - **高可读性防丑纪律**：无外侧粗黑框，仅保留清晰行间浅灰细横线；深主色首行表头（白字 `13pt Bold`）+ 偶数行极浅斑马纹 `#F8FAFC`；关键高潮环节（如抽奖/主旨演讲）整行用极浅强调色（如 `#EFF6FF`）高亮；单元格正文统一 `>=12pt`，单表超过 `8–9` 行立即拆成上下半场两页，绝不硬缩字号。

---

## <a id="pattern-process-pipeline"></a>6. 流程步骤 / 科研方法管线 / 玩法机制（`process_pipeline` / `funnel_flow`）

- **适用场景**：科研 Method Pipeline、商业增长链路、活动互动玩法步骤、漏斗转化模型。
- **横向管线语法**：
  - `4–5` 步线性流：上排 `buildRoundedTrapezoidPath` / 切角步骤头或数字徽章（`01..05`）+ `connector` 细箭头串联；下排对应等宽瑞士细线列（顶部细线 + 关键动作 + 产出物标签），底部可配 1 条反箭头闭环说明。
- **漏斗语法**：
  - 左 `44%` 放 `3–4` 层居中渐窄圆角倒梯形（`buildRoundedTrapezoidPath` + 同色系由深到浅渐变），右 `52%` 与每层水平齐平放「阶段定义 + 核心动作 + 转化指标」，中间用水平虚线精准对齐。

---

## <a id="pattern-comparison-ablation"></a>7. 科研消融实验表 / 竞品参数对比 / 正反对照（`comparison_table`）

- **适用场景**：论文消融实验（Ablation Study）、产品参数矩阵、竞品对比、内训「✅ 推荐做法 vs ❌ 常见误区」。
- **学术三线表 / 商业对比表语法**：
  - 采用顶底粗线（`1.5–2px`）+ 表头底细线（`1px`）+ 极淡行分隔的**瑞士三线表质感**；**我方方案 / 最优实验行（Ours）**整行用浅主色高亮 + 关键最优数值加粗标强调色；底部留 `44px` 结论洞察条（Action Takeaway）。
- **双栏正反对照语法**：左右各 `556px`（中间 `40px` 留白），左栏用柔和红/灰锚条标「痛点 / 误区」，右栏用主蓝/翠绿锚条标「解法 / 规范」，每条左右严格水平对齐一一映射。

---

## <a id="pattern-dual-chart-insight"></a>8. 双图洞察 / 述职计分卡 / 一页纸 Bento / 杂志图文

- **<a id="pattern-dual-chart-insight"></a>双图洞察（`dual_chart_insight`）**：左 `58%` 放 `s.charts.add()` 真 `.xlsx` 可改数图表（柱/折线/条形），右 `38%` 放「1 句加粗核心结论 + 2 个大数字拆解卡 + 1 段业务归因」，图表底部必附数据口径注脚。
- **<a id="pattern-kpi-scorecard"></a>述职计分卡（`kpi_scorecard`）**：上排 `3–4` 张极简无框指标块（`1px` 顶部色条 + `40pt Bold` 大数 + 同比/达成率胶囊标签），下排左 `55%` 趋势图 + 右 `42%` 核心归因与下步动作。
- **<a id="pattern-executive-bento"></a>老板一页纸 Bento（`matrix_grid`）**：按 `12 列 × 2 行` 异形网格划分 `4–5` 个功能块（如上左 `7` 列核心战略 + 上右 `5` 列核心 KPI；下左 `4` 列里程碑 + 下中 `4` 列资源需求 + 下右 `4` 列风险预警），块间统一 `16px` 间距、统一极浅底 `#F8FAFC` + 仅 1 块核心结论区用深主色反白聚焦视觉重心。
- **<a id="pattern-editorial-split"></a>杂志图文（`editorial_freeform` / `evidence_showcase`）**：采用非对称黄金比例（左 `42%` 全高裁切主图 + 右 `54%` 宽裕留白大标题与 3 段结构化论点），严禁四平八稳上下均分切豆腐块。
