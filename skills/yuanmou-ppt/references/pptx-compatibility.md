# PPTX 字体与跨软件兼容检查规范

制作或交付 `.pptx` 时先核对实际字体与字重；出现 PowerPoint / WPS / Keynote / LibreOffice 间文字漂移、孤字换行或跨软件交付需求时，按以下清单逐项定位并修复：

## 1. 字体与字重核对
- 核对正文、主题、母版及版式的实际字体设置，确认本机与目标软件均可解析对应的字体全名与字重（Regular / Medium / Bold / Heavy）。
- 检查嵌入字体与中西文字体绑定：避免声明常规中文字体却回退到过细 Light 字重导致标题视觉发虚。
- 替换字体后必须重新渲染并放大检查窄标题条、数据卡、结果数字与带色标签，排查孤字换行、上下漂移或越界。

## 2. 文本框与对齐（严禁空格占位）
- 必须使用原生段落缩进、制表位、对齐属性或原生表格单元格定位文字；**严禁用长串空格定位横排标签**（跨软件字体宽度差异极易导致溢出折行）。
- 核对 `wrap`、内边距、垂直锚定（`verticalAlignment`）与段间距；固定版式中禁止依赖自动扩框破坏外轮廓。
- 带底色节点的文字归属遵循 [结构还原与图形内文字规范](structure-and-text.md)（单图形直接承载底色与富文本）。

## 3. 组合坐标与并行渲染隔离
- 组合内对象按父组的 `off / ext / chOff / chExt` 换算到画布绝对坐标后再做边界与碰撞检查；若需拆组，逐级保留子对象的真实位置、尺寸、旋转、翻转与图片裁切。
- **多页并行渲染隔离**：并发调用 LibreOffice 渲染多页时，每个进程必须使用独立的用户配置目录（`-env:UserInstallation=file://...`）与独立输出目录，防止进程互相锁死。
